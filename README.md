# Todo DevOps Application

A full-stack Todo application built to demonstrate complete DevOps workflow.

## Tech Stack

- React
- Node.js
- Express
- MongoDB
- Mongo Express
- Docker
- Docker Compose
- GitHub Actions

## Features

- Create Todo
- Update Todo
- Delete Todo
- Mark Complete
- Search Todos

## DevOps Features

- Feature Branch Workflow
- Pull Requests
- GitHub Actions CI
- Docker Image Build
- Multi-container Application
